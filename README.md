# 🖼️ CodeAlpha Image Gallery

A modern and responsive Image Gallery built using **HTML, CSS, and JavaScript**.

The gallery allows users to browse images by category, view images in a lightbox, and enjoy a clean and responsive design.

---

## 🌐 Live Demo

🔗 **Live Website:**  
https://sirisha202505.github.io/HTML-Practice./

---

## ✨ Features

- 🖼️ Responsive image gallery
- 🌿 Nature image category
- 🐾 Animals image category
- ✈️ Travel image category
- 🔘 Category filter buttons
- 🔍 Lightbox image preview
- ❌ Close button for lightbox
- ✨ Image hover effects
- 📱 Mobile responsive design
- 💻 Works on desktop, tablet, and mobile devices

---

## 🛠️ Technologies Used

- **HTML5** – Structure of the webpage
- **CSS3** – Styling, animations, responsive design
- **JavaScript** – Image filtering and lightbox functionality
